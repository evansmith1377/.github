# Contributing

Thanks for taking the time to contribute!

This is the default contributing guide for repositories owned by
[@evansmith1377](https://github.com/evansmith1377) that don't provide
their own. If the repository you're contributing to has its own
`CONTRIBUTING.md`, follow that one instead.

## Getting started

1. Fork the repository and create your branch from `main`.
2. Make your changes, following the existing code style of the project.
3. Add or update tests if applicable.
4. Make sure the project builds and existing tests pass.
5. Open a pull request describing your changes.

## Reporting bugs

Please use the repository's **Bug report** issue template and include:

- A clear description of the problem
- Steps to reproduce it
- What you expected to happen
- Relevant environment details (OS, version, etc.)

## Suggesting features

Please use the repository's **Feature request** issue template and describe
the problem you're trying to solve, not just the solution you have in mind.

## Pull requests

- Keep pull requests focused on a single change where possible.
- Reference any related issues in the description (e.g. `Closes #123`).
- Be responsive to review feedback.

## Code of conduct

By participating in this project you agree to abide by the
[Code of Conduct](./CODE_OF_CONDUCT.md).
