# .github

This repository holds the default **community health files** for
[@evansmith1377](https://github.com/evansmith1377)'s repositories.

Any repository owned by this account that does not define its own copy of
these files will automatically inherit the ones defined here, per
[GitHub's default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

## What's in here

- [`ISSUE_TEMPLATE/`](./ISSUE_TEMPLATE) — issue form templates (bug report,
  feature request, support request) used by repos without their own.
- [`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md) — default pull
  request description template.
- [`CONTRIBUTING.md`](./CONTRIBUTING.md) — default contribution guidelines.
- [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) — default code of conduct.
- [`SECURITY.md`](./SECURITY.md) — default security / vulnerability
  reporting policy.
- [`FUNDING.yml`](./FUNDING.yml) — sponsorship/funding links shown on
  repository pages.

Individual repositories can override any of these by adding their own
copy of the same file in their own `.github/` directory (or repository
root, for files that support that location).
