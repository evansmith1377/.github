# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in one of
[@evansmith1377](https://github.com/evansmith1377)'s repositories, please
**do not open a public issue**.

Instead, please report it privately using one of the following methods:

1. [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) —
   open a private security advisory on the affected repository (preferred).
2. If the repository does not have security advisories enabled, open a
   private report against this `.github` repository instead.

Please include as much detail as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept
- Any relevant logs, screenshots, or environment details

## Response

We'll do our best to acknowledge reports promptly and keep you updated as
the issue is investigated and resolved. Please give us reasonable time to
address the issue before disclosing it publicly.

## Supported Versions

Unless stated otherwise in a specific repository, only the latest released
version is supported with security updates.
